# Epic 2 – Route Planning

## E2-S01 — Planning Analysis Engine

### Goal

Create the domain service that analyses a completed route and produces planning metrics before execution.

This service is the heart of the planning phase and provides deterministic analysis without mutating game state.

### Deliverable

PlanningAnalysisService

### Scope

- Route traversal.
- Travel time estimation.
- Delay probability calculation.
- Damage probability calculation.
- Maximum reward estimation.

### Out of Scope

- SwiftUI.
- Route execution.
- Settlement.

### Dependencies

- E1-S06.
- E5-S02.

### Acceptance Criteria

- Accepts an immutable route.
- Produces deterministic analysis.
- Does not consume random numbers.
- Returns a presentation-independent model.

- [Gameplay Rules](../../Gameplay-Rules.md)
- [Epic 2](../../epics/Epic-2-Route-Planning.md)

## E2-S06 — Route Confirmation

### Goal

Lock the analysed route and transition the game into execution.

### Deliverable

Planning → Execution Transition

### Scope

- Immutable route creation.
- Planning state finalisation.
- Execution hand-off.

### Out of Scope

- Route execution.

### Dependencies

- E2-S02.
- E2-S03.
- E2-S04.
