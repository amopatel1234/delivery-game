# Story Catalogue

This folder is the canonical Story Catalogue for the Delivery Game MVP.

It decomposes the approved implementation epics into implementation-sized stories with dependencies, acceptance criteria and a recommended delivery order. GitHub Issues, Project items and implementation workstreams are derived from these files; they are not the source of truth.
